# Vivo Calendar Global

Независимое приложение-календарь для Android, вдохновлённое интерфейсом vivo OriginOS Calendar.

Проект создан с акцентом на лаконичный дизайн, удобную навигацию и визуальный стиль OriginOS с адаптацией для глобального использования.

### Основная информация

• **Разработчик:** TMGeek  
• **Пакет:** `com.tmgeek.vivocalendarglobal`  
• **Платформа:** Android  
• **Темы:** Светлая / Тёмная  

## Возможности

- Просмотр календаря по месяцам
- Просмотр года
- Светлая и тёмная темы
- Интерфейс, вдохновлённый vivo OriginOS Calendar
- Адаптация для глобального использования
- Отображение событий календаря
- Современный минималистичный интерфейс
- Плавная навигация

## Установка

1. Скачайте APK из раздела **Releases**.
2. Разрешите установку приложений из сторонних источников.
3. Установите приложение.
4. При первом запуске предоставьте приложению запрашиваемые разрешения, необходимые для работы календаря.
