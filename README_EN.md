# Vivo Calendar Global

An independent Android calendar application inspired by the vivo OriginOS Calendar interface.

The project focuses on clean design, convenient navigation and the visual style of OriginOS, adapted for global use.

### Project information

• **Developer:** TMGeek  
• **Package:** `com.tmgeek.vivocalendarglobal`  
• **Platform:** Android 12+  
• **Themes:** Light / Dark  

## Features

- Monthly calendar view
- Year view
- Light and dark themes
- Interface inspired by vivo OriginOS Calendar
- Adapted for global use
- Calendar event support
- Modern minimalist interface
- Smooth navigation

## Installation

1. Download the APK from **Releases**.
2. Allow installation of apps from unknown sources.
3. Install the application.
4. On first launch, grant the permissions requested by the application that are required for calendar functionality.
